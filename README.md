# Digital Snowglobe
## Structure
Classic HTML/CSS/JS combo. I followed the hackclub jam tutorial (https://jams.hackclub.com/jam/custom-snowglobe) and then added a few of my own elements to make it unique.
For the snow particles I used the TsParticles library (https://cdn.jsdelivr.net/npm/tsparticles@2.11.0/tsparticles.bundle.min.js.) as it's shown in the `particles.json`
## Customization
Besides following the guide, I also made a little doodle to go inside the globe, added christmas music and a fading frame so that it doesn't look so flat.
## Usage
By clicking it, the globe plays a short shaking animation and starts and the particles play creating a snow like effect, simultaneosly a short clip of 'we wish you a merry christmas' plays.
